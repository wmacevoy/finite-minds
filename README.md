# finite-minds

Resources for the course *Finite Minds*.

## Talks

- [Every Breath](https://wmacevoy.github.io/finite-minds/exhalations/): how one exhale reshapes the weather, and who gets born. A general-audience talk inspired by Ted Chiang's "Anxiety Is the Dizziness of Freedom" (*Exhalation*, 2019). Source in [`docs/exhalations`](docs/exhalations).
## Lecture notes

- [Reason](https://wmacevoy.github.io/finite-minds/reason/): reasoning with certainty and with uncertainty, deduction vs induction vs abduction, and a field guide to common mistakes, worked through interactive 4×4 sudokus. Source in [`docs/reason`](docs/reason).
