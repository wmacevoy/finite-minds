# Midjourney prompts for *Every Breath*

Generate these, then save your picks to `docs/exhalations/images/` under the file names given. PNG or JPG, under about 15 MB each.

## Style suffix

Append to every prompt so the set matches:

```
documentary photograph, crisp cold morning, breath visible as soft vapor, natural light, 35mm, shallow depth of field, warm and hopeful --style raw
```

To keep the four people consistent between the opening and closing collages, pass the opening image's URL to `--cref` when generating the wide shot.
